# Friction

Append a line whenever something annoys you *while*
you're doing it — waste, re-work, ambiguity, a brief
that needed three passes, a convention that bit you.

No format. No agent. No schedule. Free-form text.
A date helps when re-reading; skip it if it slows you.

## Read it yourself every few weeks

If you find a pattern worth acting on, act.
If nothing stands out, the system is working.

## Exit criterion

If after ~6 weeks this file has fewer than ~5 real
entries, things are fine — don't build more around it.
If it ever gets too long to skim in 2 minutes, *then*
bring in an agent to summarize. Not before.
